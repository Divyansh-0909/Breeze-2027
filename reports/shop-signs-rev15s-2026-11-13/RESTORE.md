# Realistic shop boards / Rev15S

Restore the complete packed native master using the numbered parts in `delivery/Native-Master-Parts.json`. Download all listed parts and run `python source/restore-master.py DOWNLOAD_DIRECTORY NEW_OUTPUT.blend --index delivery/Native-Master-Parts.json` from this revision directory. Each part and the complete file are checked before the output is installed. Open the result in Blender 4.3.2. The current scene is `REV15S / Reference-led realistic shop name boards`; the 47 prior native scenes are retained. Images are packed, so no earlier archive is needed to open this master.

`delivery/Rev15S-Shop-Board-Additions.blend` is the smaller asset library for the new frames, painted faces, labels and bracket lamps. It is not the whole environment. The source checkpoint contains this library, the original sign artwork and generation source, photographic references, review PDF, renders, evidence and checksums.

To regenerate the artwork, run `python source/make-sign-art.py` with Pillow, NumPy, Raqm, Noto Devanagari and DejaVu fonts. Textures are original graphics; the reference photos are not used as scene textures. To rebuild the native edit, restore the Rev15R source master at the explicit path in `source/build.py`, then run `blender -b -t 2 --python source/build.py`. The build writes its full master into `/dev/shm`; adjust that output path for a persistent restoration. `source/render.py` creates the matching-camera comparisons and actual night views, and `source/create-review.py` creates the PDF with ReportLab/pypdf.

The accepted open-shop mesh data and positions are shared unchanged in the new scene. Only their shop labels are covered/replaced, with physical fascia assemblies added in front of the lintel. Each board has two warm 10 W sign lamps. All 189 crowd members, eight murals, closed artist shutters, night world/exposure/haze and original controller source are retained.

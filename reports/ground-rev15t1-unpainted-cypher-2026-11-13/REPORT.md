# Rev15T1 / Unpainted cypher road

13 November 2026. The user requested removal of the painted circle from the cypher road. The paint is removed from the colour and roughness atlases in a new Rev15T1 scene. The underlying asphalt, resurfacing patch, potholes and other road details remain.

The pixel comparison confines all changed colour and roughness pixels to the previous ring. The normal map is identical. All native mesh data and transforms remain shared unchanged with Rev15T. The exported GLB's primitive geometry, normals, UVs, indices and node transforms match the previous ground asset; its embedded colour pixels match the unpainted source.

The scene retains all 189 crowd members, eight mural states, shops, lighting, original ramp and movement route. The 49 historical scenes remain, and the active scene is Rev15T1. The old raised chalk-arc objects remain hidden. Full-world public website integration remains pending.

The editable material delta and updated runtime ground GLB have been uploaded and verified. The incremental checkpoint uses the already verified complete Rev15T master as its base. A fresh Blender process successfully reconstructed the edited 50-scene master from that base and the packed material delta; see RESTORE.md.

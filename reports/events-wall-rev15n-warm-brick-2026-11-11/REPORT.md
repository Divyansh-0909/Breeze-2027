# Events on the existing house wall / Rev15N

The user requested a Team-like wall finish for Events that blends with the cypher, expressly excluding black, then clarified that only the existing house wall should be used. This revision uses the L2 house facade itself. It removes the separate plaster display, its foot skirt and five battens from the current scene, while retaining them in the previous 43 scene memberships and original master.

Warm grey/taupe masonry reuses the exact existing Team brick substrate node group: world-space Y/Z mapping, 2.48 m tile width, the same packed image, mortar pattern, worn grain and 7 mm bump-distance setting. A new colour ramp uses the substrate height for a non-black palette. The Team materials and black finish are unchanged. A bounded shader mask applies only to the inward-facing lower Events facade, Y25.2–37, Z7.199–9.82, X−16.4 to−14.8. Outside that region the original shader is retained.

The house shell and its existing render-repair object have independent mesh/material copies, with identical vertex coordinates and topology. There is no new wall plane, box, facade overlay or closed-off aperture. All doors, windows, shutters, balcony rails, structural beams and upper floors remain. Eight existing poster images are mounted on the solid piers, clear of the door/window intervals, at 78% of their previous size. Their ratio, artwork and image data are unchanged. The heading reads Events and sits over the left bay, clear of the central column. The three components of the dedicated display light move to the beam; source light power, colour and orientation remain.

`delivery/Gullyverse-Rev15N-Events-House-Wall.blend` is the current full environment. It has 44 scenes, all images packed and no linked libraries. All 43 prior scene object memberships remain. The original Rev15M file is unchanged. The 189 people, eight mural compositions, Team black wall and 72-cell sponsor-logo spacing/10,676-frame loop remain. The Rev15N mural controller is independent of previous versions.

Source scripts, baseline inventories, opening bounds, material/mounting manifest and validation evidence are included. Native before/after, cypher-context and close-up screenshots are in `renders/`; the review PDF and gallery show the design for visual review. Poster artwork is still the existing placeholder content; new Events artwork or web-route integration has not been added.

# Rev15P local pilot recovery

Rev15O remains the authoritative environment. This isolated Rev15P experiment is not promoted. The latest document prompt explicitly prohibits Drive writes/uploads, so this phase is preserved locally only. No production route, current-pointer document, commit, push, PR or deployment was changed.

Open `delivery/Gullyverse-Rev15P-Night-Atmosphere-Pilot.blend` in Blender 4.3.2 or compatible. The active scene is `REV15P / Isolated Night Atmosphere Pilot`; all 45 original scenes are retained, for 46 total. The source master remains at the original Rev15O path and has SHA-256 `2c78b57e97a5a97683f946d60ad265b22a1eb88ae12abed6220ec268ce473657`. The pilot hash is in `evidence/preservation.json` and the checkpoint index. Original images are packed; fresh-open evidence verifies the eight independent mural states and source scene preservation.

To open the private viewer from this checkout, run `python reports/night-atmosphere-rev15p-pilot-2026-11-11/source/serve.py`, then open `http://127.0.0.1:8765/`. This loopback server serves only pilot viewer files plus the existing installed Three.js dependency. It does not start or serve the website. Stop it with Ctrl+C.

The plain GLB is the default because Draco changes the decoded triangle count. `?draco` explicitly loads the experimental compressed option; `?mobile` selects the documented mobile rendering ratio. The three camera buttons match the native fixed comparison cameras. The fog toggle gives a clear-atmosphere control, not a recreation of original Rev15O lighting. The HTML Festival directions remain available without relying on the distant sign; reduced motion pauses the LED scroll.

For a standalone restore, extract the local checkpoint and verify every entry against INDEX.json. It includes the full packed pilot master, native before/after captures, browser captures, report, shaders, runtime assets and source/verification scripts. The viewer needs Three.js 0.169.0; `vendor/three` in the checkpoint contains the exact installed runtime and loader/decoder modules. The local server uses that bundled vendor directory when present, otherwise the checkout's node_modules/three. The complete Next/React application is not a dependency of this viewer. Neither the source Blender master nor a Drive connection is required to open the packed pilot.

Rebuild order from this checkout, if needed: `source/build.py` (requires the unchanged O source), `source/render.py`, `source/export.py`, `source/optimize.mjs`, `source/paint-projection.py`, `source/fix-paint.py`, then `source/optimize.mjs` again, followed by browser verification and PDF generation. The packed pilot itself provides all source artwork for recovery. Original graph projection is evaluated during paint conversion; fine enamel noise is approximated in the web material. Ground lighting has an explicit second UV and Three.js lightMap binding, while the full scene's static lighting is not completely baked.

The performance report records cloud SwiftShader software measurements and low sample counts. They do not certify desktop hardware, a physical phone, mobile thermals or full-world production integration. The pilot misses the requested FPS goals in this environment. KTX2/Basis encoding is not delivered because no encoder is installed; browser compressed-format capability alone does not prove a working encoded pipeline. Review those limits before considering a larger rollout.
